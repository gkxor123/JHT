# SlideCap — 강의 영상 → PPT 슬라이드 자동 캡처

> 같은 저장소의 **PPT2PDF**(PPT 여러 개 → PDF 일괄 변환)는 [`ppt2pdf/README.md`](ppt2pdf/README.md)를 보세요.

연수강좌처럼 PPT를 띄워 놓고 강의하는 영상에서, 사용자가 지정한 **PPT 화면 영역**만
슬라이드가 바뀔 때마다 자동으로 캡처해 **.pptx 파일**로 만들어 줍니다.

## 사용법 (Windows)

1. `SlideCap.exe` 실행 (설치 필요 없음).
   영상 파일이나 폴더를 exe 아이콘이나 프로그램 창에 **끌어다 놓아도** 됩니다.
2. **영상 파일 추가** 또는 **폴더 추가** (폴더 안의 영상을 모두 추가합니다).
3. **▶ 시작** → PPT 영역을 **자동으로 찾습니다**(옵션 "PPT 영역 자동 인식", 기본 켜짐). **묻지 않고** 바로 진행하며,
   애매하면 영역을 넉넉하게 잡고 영상 옆에 `slidecap_region.jpg`(잡은 영역 미리보기)를 남깁니다.
   옵션을 끄면 예전처럼 영역을 직접 드래그해서 지정합니다
   - 모서리나 변을 끌면 크기 조절, 안쪽을 끌면 이동
   - 아래 슬라이더로 영상의 다른 시점 화면을 볼 수 있습니다.
   - 강사 웹캠이 슬라이드 위에 겹쳐 있으면 **제외 영역**으로 드래그 (선택 사항.
     계속 움직이는 영역은 지정하지 않아도 자동으로 무시합니다)
4. 영역을 정하고 나면 나머지는 자동으로 진행됩니다. 결과 `영상이름.pptx`는 영상과 같은 폴더에 저장됩니다.
   - 슬라이드 메모(노트)에 해당 장면의 **영상 시간**이 적혀 있습니다.

같은 강좌 시리즈처럼 화면 배치가 같은 영상이 여러 개면 **"첫 영상의 영역을 똑같이 적용"**을 켜 두세요.
영역은 처음 한 번만 물어봅니다. 해상도가 달라도 비율에 맞춰 자동으로 조정합니다.
목록에서 영상을 더블클릭하면 그 영상의 영역만 따로 지정할 수 있습니다.

## 캡처 규칙

| 상황 | 동작 |
|---|---|
| 슬라이드 넘김 (페이드 등 전환 효과 포함) | 전환이 끝난 뒤 1장 캡처 |
| 빈 바탕에 글씨·그림이 하나씩 추가됨 | **마지막 장면만** 저장 (옵션으로 단계별 저장 가능) |
| 그림이 바뀜 (angiogram 연속 장면, 그림 교체, 그림 위 화살표) | 장면마다 캡처 |
| 마우스 커서, 레이저 포인터 움직임 | 무시. 저장 이미지에서도 움직이는 커서는 지워짐 |
| 커서가 사라졌다/나타남 | 무시 (커서 없는 쪽 이미지 사용) |
| GIF, 슬라이드 안 동영상, 웹캠 | 움직임은 무시하고 슬라이드는 1장만 캡처 |
| Zoom 등 채팅 알림 상자 (화면 아래 가장자리의 작은 어두운 상자) | 무시. 알림이 없는 장면을 저장 (함께 움직이는 GIF도 무시) |
| 앞 슬라이드로 되돌아감 | 이미 저장된 슬라이드면 건너뜀 (옵션) |

**민감도**
- 보통: 권장
- 높음: 아주 작은 변화도 잡음
- 낮음: 큰 변화만 잡음

**알려진 한계**
- 1~2초 간격으로 프레임이 바뀌는 느린 GIF는 처음 몇 장면이 추가로 캡처될 수 있습니다.
  강사가 그림을 클릭해 바꾸는 것과 구분하기 어렵기 때문입니다. 반복되는 장면은 중복 제거로 걸러집니다.
- 커서를 한곳에 오래 세워 두면 그 커서가 이미지에 남을 수 있습니다 (새 슬라이드로 잘못 잡지는 않습니다).
- 커서 크기 정도의 아주 작은 그림이 커서 바로 옆에 나타나면 놓칠 수 있습니다.

## 자동 모드 (.bat 파일용)

```
SlideCap.exe --auto "E:\01_Radiology\연수강좌 원본"
```

- 지정한 폴더 아래(하위 폴더 포함)에서 **아직 PPT가 없는 영상만** 찾아 처리합니다.
- **강좌 폴더**(지정 폴더 기준 2단계 아래, 예: `연수강좌 원본\01_Chest\2026-11-15 OO연수강좌`)에
  강의록으로 보이는 파일(PDF, PPT, PPTX, DOC, HWP 등)이 하나라도 있으면 그 강좌는 통째로 건너뜁니다.
  SlideCap이 만든 PPT(영상과 같은 이름)는 강의록으로 치지 않습니다.
  이름에 프로그램·안내·목차·일정·시간표·program·schedule·agenda 등이 들어간 문서도 강의록으로 치지 않습니다.
- 강의록이 일부 강의에만 있는 강좌처럼 **강의록이 있어도 변환하고 싶은 강좌**는, 그 강좌 폴더에
  `slidecap_변환.txt`(또는 `slidecap_convert.txt`) 빈 파일을 만들어 두면 됩니다. 단계는 `--course-depth N`으로 바꿀 수 있습니다.
- 처리할 영상이 없으면 창 없이 바로 끝나고, 다 끝나면 완료 알림 후 창이 닫힙니다(.bat이 다음 단계로 진행).
- 저장된 영역은 그 폴더(또는 상위 폴더)의 `slidecap_region.json`만 자동 적용합니다.
  새 강좌 폴더는 처음 한 번 영역을 묻습니다(직전 영역이 초기값으로 표시됨).
- 결과 PPT는 영상과 같은 폴더에 같은 이름으로 생깁니다.
- 새 폴더는 먼저 **PPT 영역을 자동으로 찾습니다**(영상 40장면에서 슬라이드가 바뀌는 직사각형 + 슬라이드 테두리). 확실할 때만 그대로 쓰고,
  애매하면(카메라로 찍은 프로젝터 화면 등) 찾은 영역을 미리 그려 둔 채 물어봅니다.
- 영역 지정 창은 **폴더별로 처음 한 번만** 뜹니다. 정한 영역은 그 폴더의 `slidecap_region.json`에 저장되고,
  이후 같은 폴더(또는 하위 폴더)에 추가된 영상은 묻지 않고 처리합니다.

## 명령줄 사용 (선택)

```
SlideCap.exe --cli "D:\강의\1강.mp4" --roi 40,60,960,540 [--exclude X,Y,W,H] [--out 폴더] [--sens high] [--images] [--png]
```

## 개발

```
pip install -r requirements.txt
python slidecap_main.py          # GUI 실행
python tests/test_engine.py      # 정확도 테스트 (합성 강의 영상)
python tests/test_autoscan.py    # 자동 모드 선택 규칙 테스트
pyinstaller SlideCap.spec        # exe 빌드 (dist/SlideCap.exe)
```

GitHub에 push하면 Actions(`Build Windows exe`)가 Windows에서 테스트한 뒤 exe를 빌드합니다.
빌드된 exe는 해당 실행 결과 페이지의 Artifacts에서 받을 수 있습니다.
